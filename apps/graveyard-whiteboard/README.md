# Graveyard Whiteboard

Collaborative drawing app built on the Bones CRDT kernel (`/kernel`). Strokes are CRDT elements; erased strokes become tombstones that the Graveyard panel shows.

**Status:** placeholder. Implementation is task KER-079 in `.kiro/specs/crdt-kernel/tasks.md`.

This is one of the two separate application folders required by the Skeleton Crew category (the other is `apps/cursed-checklist`).

This project is an educational CRDT implementation. It is not production-ready and does not replace Yjs, Automerge or Loro.
